# 📖 قارئ الكتب الذكي | Smart Book Reader (Book IQ)

تطبيق متطور لقراءة ملفات الـ **PDF** (كتاب القراءة وكتاب النشاط)، مبني باستخدام إطار عمل **Flutter** وفق أحدث معايير هندسة البرمجيات **Clean Architecture** مع نمط **MVC**، وإدارة الحالة عبر **Provider**، وتصميم متجاوب تماماً لكل الشاشات عبر **flutter_screenutil**.

---

## 🌟 نظرة عامة (Overview)

يوفر التطبيق شاشة رئيسية أنيقة تتيح لك الاختيار بين **كتاب القراءة** و**كتاب النشاط**، مع حفظ تقدمك في كل كتاب بشكل مستقل، ومحرك عرض فائق السلاسة للتنقل والبحث والتكبير والطباعة والمشاركة.

### 🎯 الميزات الرئيسية
- 📚 **دعم كتابين بشاشة اختيار متكيفة**:
  - **كتاب القراءة** ([`assets/pdf/c1.pdf`](assets/pdf/c1.pdf)).
  - **كتاب النشاط** ([`assets/pdf/activity.pdf`](assets/pdf/activity.pdf)).
  - حفظ واستئناف موضع الصفحة الأخيرة لكل كتاب بشكل مستقل مع عرض حالة التقدم على بطاقة كل كتاب.
- ⚡ **أداء فائق وسلاسة في التمرير وتقليب الصفحات**:
  - عزل عارض الـ PDF داخل `RepaintBoundary` و `Selector` لمنع إعادة بناء العارض أثناء التقليب.
  - وضع **التحريك السلس (Pan Mode)** افتراضياً للتمرير باللمس أو الفأرة بدون تقطيع، مع إمكانية التبديل لوضع **تحديد النص**.
  - تقليل عمليات الكتابة على القرص أثناء التمرير السريع عبر الـ Debouncing وشريط تمرير غير حاجب (`onChangeEnd`).
  - فتح الكتاب مباشرة على الصفحة المحفوظة (`initialPageNumber`) بدون تأخير.
- 🔍 **بحث نصي ذكي داخل الكتاب**:
  - شريط بحث تفاعلي للبحث عن أي كلمة أو جملة داخل الكتاب، مع عداد نتائج (`1 من 12`) وأزرار التنقل بين النتيجة السابقة والتالية.
- 🔢 **انتقال مباشر وفوري للصفحات**:
  - كتابة رقم أي صفحة (مثل 10 أو 30 أو 52) والضغط على **Enter** من لوحة المفاتيح أو زر **موافق** للانتقال الفوري.
- 🔎 **تحكم كامل بالتكبير والتصغير (Zoom Controls)**:
  - أزرار تكبير وتصغير عائمة (+ / -) وإعادة ضبط سريعة (100%)، مع دعم اللمس بالإصبعين (Pinch) والنقر المزدوج.
- 📜 **3 أوضاع للتمرير والتقليب**:
  - **تمرير رأسي سلس** (Vertical Continuous).
  - **تمرير أفقي سلس** (Horizontal Continuous).
  - **تقليب صفحة بصفحة** (Single Page Flip).
  - دعم اختصارات لوحة المفاتيح (`Ctrl+F` للبحث، `Ctrl+G` للانتقال السريع، والأسهم للتقليب).
- 🖨️ **الطباعة المباشرة (Direct Printing)** ومشاركة الملفات عبر **البلوتوث وتطبيقات التواصل الاجتماعي**.
- 🎨 **ثيمات مريحة للقراءة (Light / Sepia / Dark)** ودعم كامل للغتين **العربية** و**الإنجليزية**.

## 🏛️ الهيكلية المعمارية (Architecture Breakdown)

```text
lib/
├── core/
│   ├── constants/        # المسارات والألوان وحدود التكبير
│   ├── localization/     # التعريب والترجمة (العربية / الإنجليزية)
│   ├── theme/            # ثيمات القراءة (فاتح، داكن، سيبيا)
│   └── services/         # خدمات التخزين والطباعة والمشاركة عبر البلوتوث والتطبيقات
├── domain/
│   ├── entities/         # كينونات الكتاب (BookEntity) وإعدادات القارئ
│   ├── repositories/     # عقود المستودعات
│   └── usecases/         # حالات الاستخدام (الحفظ، الاسترجاع، وضع التمرير، الطباعة، المشاركة)
├── data/
│   ├── datasources/      # مصدر البيانات المحلي (SharedPreferences)
│   ├── models/           # نماذج البيانات
│   └── repositories/     # تنفيذ المستودعات
├── presentation/
│   ├── controllers/      # BooksController, PdfReaderController, AppSettingsController
│   ├── views/            # BookSelectionView (الشاشة الرئيسية), PdfViewerView
│   └── widgets/          # PdfTopAppBar, PdfSearchBar, PdfBottomBar, JumpToPageDialog, ...
└── main.dart
```
